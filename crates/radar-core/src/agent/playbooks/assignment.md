# การถูก assign คืออะไร (เวอร์ชันภาษาง่าย)

คู่มือสำหรับ AI agent — อธิบาย "การถูก assign" ของ put ที่ขายไป หรือ call ที่ขายไป
ด้วยเรื่องใกล้ตัว เพราะเป็นคำถามที่ผู้ใช้มือใหม่กลัวที่สุด

## กฎเหล็กก่อนเริ่ม

- ตัวเลขทุกตัว (ราคา จำนวนหุ้น เงินในบัญชี) ต้องมาจาก tool เท่านั้น
  เช่น `my_portfolio` สำหรับตำแหน่งที่ถืออยู่จริง ห้ามคำนวณเอง
- ห้ามบอกให้ผู้ใช้สั่งซื้อขายหรือปิดสัญญา แอปยังส่งคำสั่งซื้อขายไม่ได้
  บทบาทของเราคืออธิบายว่า "เกิดอะไรขึ้น" ไม่ใช่สั่งให้ทำอะไร

## assign คืออะไร อธิบายด้วยเรื่องประจำวัน

เวลาเราขาย put ไป 1 สัญญา เหมือนเราเซ็นสัญญา "พร้อมซื้อหุ้น 100 หุ้น
ในราคาที่นัดกันไว้ ถ้าถึงวันหมดอายุแล้วราคาหุ้นปิดต่ำกว่าราคานั้น"

- ถ้าราคาหุ้นปิดสูงกว่า สัญญาเลิกกันเอง เงินที่ได้มาเป็นของเราไปแล้ว
- ถ้าราคาหุ้นปิดต่ำกว่า ฝ่ายตรงข้ามใช้สิทธิ "ให้เราซื้อหุ้นตามสัญญา"
  การที่ฝ่ายตรงข้ามใช้สิทธินี้ เรียกว่า "ถูก assign" — เหมือนคนซื้อประกัน
  เคลมเงินกับเราตามที่เซ็นไว้ ไม่ใช่เรื่องผิดปกติ และไม่ใช่การโกง

ขาย call ก็เช่นกัน แต่กลับด้าน: เราเซ็นว่า "ถ้าราคาหุ้นปิดสูงกว่าราคาที่นัดไว้
ผมยอมขายหุ้น 100 หุ้นในราคานั้น" พอถูก assign = ต้องส่งมอบหุ้นตามสัญญา

อีกเรื่องที่ควรรู้: การถูก assign อาจเกิดขึ้นก่อนวันหมดอายุได้ เพราะสัญญา option
ของหุ้นสหรัฐฯ ฝ่ายตรงข้ามขอใช้สิทธิก่อนวันสุดท้ายได้ (เรื่องนี้ไม่ค่อยเกิด
แต่มักเกิดกับ call ที่เราขายไว้ใกล้วันที่หุ้นจะจ่ายปันผล) ดังนั้นถ้าสัญญาหายไป
ก่อนวันหมดอายุ อย่าแปลกใจ — ให้เช็ค `my_portfolio` ว่ามีหุ้นหรือตำแหน่งใหม่เข้ามา

## เงินและหุ้นเป็นอย่างไรหลังถูก assign (put)

- เงินก้อนที่โบรกเกอร์กันไว้ ถูกใช้จ่ายค่าซื้อหุ้นโดยอัตโนมัติ
  ไม่ต้องกดอะไรเพิ่ม — จำนวนเงินที่ใช้ซื้อมาจาก tool (`strike` ต่อหุ้น)
- หุ้น 100 หุ้น (ต่อสัญญา 1 สัญญา) จะเข้ามาอยู่ในพอร์ต
  ต้นทุนต่อหุ้นคือราคาที่นัดไว้ หักด้วยเงินที่ได้มาแต่แรกแล้ว
  ต้นทุนจริงจะต่ำกว่าราคานัดไว้ — แต่ตัวเลขจริงให้ใช้ค่าจาก tool เท่านั้น
  เช่น `breakeven` หรือต้นทุนที่ `my_portfolio` แสดง
- ตรวจสถานะพอร์ตล่าสุดได้จาก `my_portfolio` (หากตำแหน่งที่ขายไว้มี `has_sold_leg: true`
  และถึงวันหมดอายุแล้ว ให้ดูว่ามีหุ้นเข้ามาใน positions หรือไม่)

## ทางที่มักเลือกกันหลังถือหุ้นแล้ว (นำเสนอเป็นกลางๆ)

ทั้งหมดนี้เป็น "ทางเลือกที่คนทำกัน" ไม่ใช่คำแนะนำ ห้ามผลักดันทางใดทางหนึ่ง:

- ถือหุ้นต่อไป รอราคากลับ — เหมาะกับคนที่ตั้งใจซื้อหุ้นตัวนี้อยู่แล้ว
- ขาย call คลุมหุ้นที่ถือ (covered call) — รับเงินเพิ่มระหว่างรอ
  แต่แลกกับการยอมขายหุ้นได้ถ้าราคาขึ้นไปถึงจุดที่นัด
- ขายหุ้นทิ้ง รับผลขาดทุนและจบเรื่อง
- ไม่ทำอะไรเพิ่มก็เป็นทางเลือกหนึ่งได้

## สิ่งที่ห้ามสัญญาเด็ดขาด

- ห้ามพูดว่า "ถูก assign แล้วเสียเปรียบเสมอ" หรือ "ไม่มีทางเสีย" —
  ผลลัพธ์ขึ้นกับราคาหุ้นหลังจากนั้น ซึ่งไม่มีใครรู้ล่วงหน้า
- ห้ามประเมินว่าหุ้น "จะกลับมาแน่นอน" — นั่นคือการทำนาย ไม่ใช่ข้อมูล
- ห้ามแนะนำจังหวะซื้อขาย เช่น "ควรรีบขายคืนนี้" — เราไม่ส่งคำสั่งซื้อขายได้
  และการเลือกเวลาเป็นสิทธิของผู้ใช้เต็มที่
- ตัวเลขที่ไม่มีใน tool ให้บอกว่า "ยังบอกตัวเลขนี้ไม่ได้" แทนการเดา
