# UX/UI Review — PREMIUM RADAR · 2026-11-25

> รีวิวหน้าจอปัจจุบันเทียบกับเป้าหมายสูงสุดของโปรเจค ยังไม่ใช่แผนลงมือ
> สิ่งที่ตกลงกันแล้ว: แยก **โหมดง่าย** (ค่าเริ่มต้น สำหรับภรรยาของ THP) กับ **โหมดละเอียด** (terminal ปัจจุบัน สำหรับ THP)

## 0. เป้าหมายที่ใช้เป็นเกณฑ์

> แอปที่มี AI agent เป็นผู้ช่วยลงทุน option ภาษาไทย ใช้วิธีคิดแบบ OI trader หาโอกาสขาย premium ที่แม่นยำ อธิบายจนคนที่รู้แค่ว่า option คืออะไรตัดสินใจเองได้ อนาคตอาจให้ agent ส่งคำสั่งซื้อขายให้ได้ด้วย โดยเชื่อมกับ Webull ผ่าน MCP และ Skills ของทางการ

**ผู้ใช้หลัก:** ภรรยาของ THP รู้แค่ว่า option คืออะไร ไม่รู้เรื่อง delta, IV, OI หรือวิธีใช้แอปเทรด อยู่ในไทย จึงคิดเวลาเป็นเวลาไทย
**คำถามตัดสิน:** "เธอเข้าใจและกล้าตัดสินใจเองไหม"

## 3. Findings

ระดับ: 🔴 ขวางเป้าหมายโดยตรง · 🟠 ทำให้เข้าใจผิดหรือสับสน · 🟡 ขัดใจ แต่ยังใช้ได้

### 🔴 UX-01 ส่วนที่ "เล่าเรื่อง" ของต้นแบบหายไป
- **ที่:** แผง Contract Analysis
- **ตอนนี้:** `Premium / Annualized / Collateral / Breakeven` + Webull quote (`Bid/Mid/Ask, Delta, Gamma, Theta, Vega`) + แถบ `OTM 76% · Near 10% · ITM 22%`
- **ต้นแบบ (`ref-1`):** มีกล่อง "ความหมาย / เงิน / กันชน" และผลตอนหมดอายุ 3 กรณีพร้อมโอกาส เช่น "หุ้นปิดสูงกว่า $145 → ไม่โดนซื้อ เก็บเงินครบ +$183 โอกาส 72%" แล้วปิดด้วย "สรุป / เหมาะกับ / ข้อควรระวัง"
- **ทำไมสำคัญ:** เป็นส่วนเดียวบนหน้าจอที่แปลตัวเลขเป็นผลต่อเงินของเธอ และเป็นจุดเด่นที่สุดของต้นแบบ
- **ทิศทาง:** ทำการ์ด 5 คำถามเป็นแกนของโหมดง่าย: ได้เงินเท่าไร / แลกกับอะไร / โอกาสแค่ไหน / ทำไมช่วงนี้น่าทำ / แย่สุดคืออะไร ส่วนผล 3 กรณีให้อยู่ในข้อ "โอกาสแค่ไหน"

### 🔴 UX-02 ศัพท์เทคนิคภาษาอังกฤษทั่วหน้าจอ
- **ที่:** ทุกหน้า
- **ตัวอย่าง:** `Delta, Assign, Credit $, Return, Ann%, Collateral $, B/E, OI, IV (ATM), Expected move ±1σ, Put/Call skew, Put/Call OI, Lowest delta / Balanced setup / Highest annualized, Moderate δ .15–.30, OTM/Near/ITM`
- **ต้นแบบทำดีกว่า (`ref-4`):** ตัวกรองเขียนว่า "ขาย Put (รับหุ้น)", "ขาย Call (มีหุ้นอยู่แล้ว)", "ต่ำ (assign ~10–20%)" ส่วนการ์ดเขียนว่า "ปลอดภัยสุด / สมดุลสุด / ผลตอบแทนสูงสุด (เสี่ยง > 60%)"
- **ทิศทาง:** โหมดง่ายห้ามมีศัพท์ option ในข้อความหลัก โหมดละเอียดยังใช้ศัพท์ได้ แต่ทุกคำต้องมีคำอธิบายไทยเมื่อชี้

### 🔴 UX-03 ไม่มีจุดเริ่มต้นและไม่มีการตัดสินใจหลัก
- **ที่:** หน้า Options (`now-live-monitor`)
- **ตอนนี้:** หน้าจอเดียวมีกราฟราคา, การ์ดสถิติ 6 ใบ, การ์ดแนะนำ 3 ใบ, ตาราง 12 คอลัมน์ 93 แถว, แผงขวาที่มี greeks และรายการซื้อขาย และแผงซ้ายที่มีตัวกรอง 4 กลุ่ม
- **ทำไมสำคัญ:** ขัดกับหลัก "One decision per screen" ใน `docs/dev/PRODUCT.md` เอง สำหรับมือใหม่ ข้อมูลที่ครบไม่ได้ช่วยตัดสินใจ แต่ทำให้ตัดสินใจไม่ได้
- **ทิศทาง:** โหมดง่ายให้ 1 จอมี 1 คำถาม ตารางเต็มย้ายไปอยู่ในโหมดละเอียด

### 🔴 UX-04 ตัวกรองถามสิ่งที่ผู้ใช้ตอบไม่ได้
- **ที่:** แผงซ้าย STRATEGY SCANNER
- **ตอนนี้:** `Strategy: All/Put/Call` · `Assignment risk: All / Low δ.10–.20 / Moderate / High` · ชิปวันหมดอายุ · `Available cash (USD)`
- **ทิศทาง:** เปลี่ยนเป็นคำถามที่เธอตอบได้
  1. "ถ้าราคาลง อยากได้หุ้นตัวนี้ไหม" → กำหนดท่าที (อยากถือ = ยอมให้โดน assign / ไม่อยากถือ = หลบ assign)
  2. "มีเงินเท่าไร"
  3. "รอได้นานแค่ไหน" (1 สัปดาห์ / 1 เดือน)
  4. "รับความเสี่ยงได้แค่ไหน" แสดงเป็น "โดนซื้อหุ้นประมาณ 1 ใน 10 / 2 ใน 10 / 3 ใน 10 ครั้ง"

### 🟠 UX-05 ตัวเลขที่ชวนให้เลือกผิด
- **ที่:** การ์ด "HIGHEST ANNUALIZED · TSLA 372.5P · 90.9% annualized" และคอลัมน์ `Ann%`
- **ปัญหา:** ผลตอบแทนต่อปีของสัญญา 4 วันดูเหมือนได้ 90% ต่อปีจริง และการ์ดนี้เด่นเท่ากับตัวที่ปลอดภัยกว่า ทั้งที่โอกาสโดน assign สูงกว่า
- **ทิศทาง:** โหมดง่ายแสดงเงินจริงที่ได้ ($360) และ % ของเงินที่วางไว้ในช่วงนั้น (0.97% ใน 4 วัน) ไม่แสดงผลตอบแทนต่อปีเป็นตัวเลขหลัก การ์ดความเสี่ยงสูงต้องมีป้ายเตือนชัดเหมือนต้นแบบ ("เสี่ยง > 60%")

### 🟠 UX-06 หน้า Home ไม่ตอบเป้าหมาย
- **ที่:** `now-live-home`
- **ตอนนี้:** ขึ้นแรงวันนี้ (WETO +239%, BNAI +117%), ลงแรงวันนี้, ซื้อขายหนาแน่น, ตาราง watchlist ว่าง, การ์ด "LAB CAPTURE 1 วัน"
- **ปัญหา:** หุ้นที่ขึ้นลงแรงส่วนใหญ่เป็นหุ้นเล็กราคาต่ำกว่า $1 ไม่เกี่ยวกับการขาย premium และเสี่ยงสำหรับมือใหม่ ส่วน Lab capture ก็ไม่มีความหมายกับเธอ
- **ทิศทาง:** Home ของโหมดง่ายตอบ 3 อย่าง: (1) วันนี้ agent เจอโอกาสอะไรในหุ้นที่สนใจ (2) สัญญาที่ขายไปแล้วตอนนี้เป็นอย่างไร (3) ตลาดเปิดอีกกี่ชั่วโมงตามเวลาไทย

### 🟠 UX-07 Agent รอให้ถามก่อน
- **ที่:** Radar Assistant (ปุ่มลอยมุมขวาล่าง)
- **ตอนนี้:** ข้อความต้อนรับ "ถามเกี่ยวกับสัญญาในตารางได้เลย เช่น 'มีเงิน $18,000 ตัวไหนน่าทำ?'"
- **ปัญหา:** มือใหม่ไม่รู้จะถามอะไร และเป้าหมายต้องการ agent ที่เป็นฝ่ายเสนอ
- **ทิศทาง:** ในโหมดง่าย agent อยู่กลางจอ เปิดมาก็เสนอทันที ("สัปดาห์นี้มี 2 ตัวที่น่าสนใจ…") และตอบต่อในบริบทของการ์ดที่เปิดอยู่

### 🟠 UX-08 เวลาเป็น ET ทั้งหมด
- **ตัวอย่าง:** `After-hours · 19:08:52 ET`, รายการซื้อขาย `16:14:24 ET`, `ATH · ล่าสุด 16:00:00 ET`
- **ทิศทาง:** แสดงเวลาไทยเป็นหลัก ET เป็นตัวรอง และบอกสถานะเป็นภาษาคน เช่น "ตลาดเปิดอีก 3 ชม. (21:30 น.)" หรือ "ตลาดปิดแล้ว ราคานี้คือราคาปิดเมื่อคืน"

### 🟠 UX-09 ข้อความของนักพัฒนาโผล่ใน UI
- **ตัวอย่าง:** "ฐานปริมาณตามที่ API ส่ง (ยังไม่ยืนยัน adjusted/crude)", "Funnel: OTM → delta → DTE → spread → premium → budget", "ดึงราคา snapshot 373/373", "Webull REST · เวลาซื้อขายปกติ (ET) · … · แสดงสูงสุด 20 ตัว", `Feed: SYNCING / IDLE`, รหัส session `ATH`, รหัสฝั่ง `B / S / N / NS` ในรายการซื้อขาย
- **ทิศทาง:** ซ่อนในโหมดง่ายทั้งหมด โหมดละเอียดให้เก็บไว้ใน tooltip หรือแผง debug

### 🟠 UX-10 Watchlist สองแบบทำให้สับสน
- **ที่:** `now-live-watchlists`
- **ตอนนี้:** มี list ในเครื่อง ("ลิสต์ว่าง") กับ watchlist ใน Webull (อ่านอย่างเดียว 7 ลิสต์) และปุ่ม "คัดลอกเข้า 'list นี้'" กับ "เปิด Radar →" ส่วนแผงซ้ายบอก `Watchlist 0 ตัว`
- **ทิศทาง:** โหมดง่ายมีรายการเดียวชื่อ "หุ้นที่ฉันสนใจ" แต่ละตัวติดป้าย **อยากถือ / ไม่อยากถือ** (ท่าทีต่อการโดน assign) ส่วนการนำเข้าจาก Webull ทำครั้งเดียวตอนตั้งค่า

### 🟠 UX-11 ไม่มีเส้นทางหลังขาย
- **ปัญหา:** แอปพาไปถึงตอน "เลือกสัญญา" แต่ไม่ได้ตอบสิ่งที่มือใหม่กังวลที่สุดหลังขายไปแล้ว: ตอนนี้เป็นอย่างไร เมื่อไรจบ ถ้าหุ้นลงต้องทำอะไร ถ้าโดน assign แล้วต่อไปทำอะไร
- **ทิศทาง:** การ์ด "สัญญาที่ขายไปแล้ว" ใน Home ของโหมดง่าย แสดงสถานะเป็นภาษาคน ("ปลอดภัย ห่างจุดที่ต้องซื้อหุ้น 6%") และมีคำแนะนำต่อตามท่าทีต่อหุ้นตัวนั้น

### 🟡 UX-12 แผงซ้ายและแผงขวาแสดงทุกหน้า
- STRATEGY SCANNER แสดงบน Home, Market และ Watchlist ที่ไม่เกี่ยว ส่วนแผงขวาแสดงสัญญาที่เลือกไว้ก่อนหน้า หรือ "รอข้อมูลจาก feed …"
- **ทิศทาง:** โหมดง่ายไม่ใช้โครง 4 คอลัมน์ โหมดละเอียดให้แสดงแผงเฉพาะหน้าที่เกี่ยว

### 🟡 UX-13 Icon rail ไม่มีชื่อ
- ไอคอน 6 ตัวทางซ้ายไม่มี label มือใหม่เดาไม่ได้ว่าแต่ละตัวพาไปหน้าไหน

### 🟡 UX-14 ตัวอักษรเล็กและ contrast ต่ำ
- ตารางประมาณ 11.4 px และ label สีเทาบนพื้น #0b0d11 ภาษาไทยที่มีสระบนล่างยิ่งอ่านยาก
- **ทิศทาง:** โหมดง่ายใช้ตัวอักษรหลักอย่างน้อย 15–16 px และตัวเลขสำคัญ 24 px ขึ้นไป

### 🟡 UX-15 ภาษาปนกันใน label เดียว
- ตัวอย่าง: "ขาย Put · CSP TSLA $372.5", "WATCHLIST · หุ้นขึ้นเด่น", "ดึงราคา snapshot", "Contracts loaded 93 live feed"

### 🟡 UX-16 ไม่มีการพาใช้ครั้งแรก
- เปิดครั้งแรกเจอตารางว่างและคำว่า "ไปหน้า Watchlists เพิ่มก่อน" ไม่มีขั้นตอนพาใช้
- **ทิศทาง:** ครั้งแรกให้ถาม 3 ข้อ (หุ้นที่สนใจ + อยากถือไหม, เงินที่ตั้งใจใช้, รับความเสี่ยงได้แค่ไหน) แล้วพาไปการ์ดแนะนำใบแรก

### 🟡 UX-17 ความเสี่ยงไม่ได้บอกเป็นเงิน
- ตอนนี้แสดง Collateral และ Breakeven แต่ไม่บอกว่า "ถ้าหุ้นตก 20% คุณขาดทุนประมาณ $X"
- **ทิศทาง:** ข้อ "แย่สุดคืออะไร" ในการ์ด 5 คำถามต้องเป็นตัวเลขเงิน และอิงสถานการณ์ที่เข้าใจง่าย

## 4. เทียบกับต้นแบบ

**ต้นแบบทำได้ดี แต่เราทำหายไปหรือยังไม่มี**
- กล่องเล่าเรื่อง: ความหมาย, เงิน, กันชน, ผล 3 กรณีพร้อมโอกาส, สรุป, เหมาะกับ, ข้อควรระวัง (UX-01)
- ตัวกรองภาษาไทยที่บอกผลลัพธ์ เช่น "ขาย Put (รับหุ้น)" หรือ "ต่ำ (assign ~10–20%)" (UX-02)
- ป้ายเตือนบนการ์ดเสี่ยง "ผลตอบแทนสูงสุด (เสี่ยง > 60%)" (UX-05)
- กราฟ payoff ที่มีคำอธิบายบนกราฟ ("กันชน $8.89 (5.8%) ก่อนเริ่มขาดทุน")
- กราฟภาพรวมหลายแบบ เช่น heatmap โอกาสโดน assign ตามวันหมดอายุ × strike และ bubble ความเสี่ยงกับผลตอบแทน

**ต้นแบบเองก็ยังไม่เหมาะกับมือใหม่**
- ยังแน่นมาก: กราฟ 15 แท็บ, ตาราง 15 คอลัมน์ และศัพท์อังกฤษในตาราง
- ไม่มี agent ไม่มีท่าทีต่อหุ้น และไม่มีเส้นทางหลังขาย
→ ต้นแบบเหมาะเป็นแหล่งไอเดียสำหรับ **โหมดละเอียด** และ **การ์ดเล่าเรื่อง** ไม่ใช่แบบให้ลอกทั้งหน้า

## 5. สิ่งที่ดีอยู่แล้วและควรเก็บไว้
- ป้ายบอกแหล่งข้อมูลอย่างตรงไปตรงมา (LIVE / API / DEMO / ราคาปิด) ตามหลัก "ข้อมูลเงียบก็แสดงว่าเงียบ"
- เกรด A/B/C พร้อมเหตุผล
- แนวคิดการ์ด 3 แบบ (ปลอดภัย / สมดุล / ผลตอบแทนสูง) แค่ต้องเปลี่ยนคำและน้ำหนักการแสดงผล
- กราฟ payoff และกราฟราคา
- terminal ทั้งชุดซึ่งจะกลายเป็นโหมดละเอียดสำหรับ THP
